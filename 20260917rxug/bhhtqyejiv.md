# 泰国试管婴儿促排期间夫妻双方需要注意什么？

> 更新时间：2026-09-17 (UTC+8)

促排是泰国试管婴儿周期的第一个重要环节，那么对于第一次接触试管的人群可能会不知所措，今天RFG泰国皇家医院小编就帮大家整理一下促排期间夫妻双方需要注意的事项。促排效果好那么取卵结果才会好!

　　泰国试管促排基本是“短方案”，也就是月经第2天或者第3天开始促排打针，促排时间一般是8-12天，促排时间和用药要看患者身体情况和医生用药方案。

　　**女方促排需要注意：**

　　1、均衡营养可使卵泡发育得更好，饮食上多摄入富含蛋白的食物，每天按时按量服用主治医生开的保健品(如叶酸、维生素C、维生素E、辅酶Q10、DHEA等);

　　2、作息规律，避免熬夜，尽量保证充足的睡眠时间;

　　3、保持衣着宽松，尽量穿裙子或宽松的裤子，不能穿紧身裤或者牛仔裤 ;

　　4、促排期间要禁止剧烈运动，不能健身，比如快步行走，跑，跳，游泳等;

　　5、禁止泡澡、桑拿和按摩，避免同房，不能有任何刺激子宫的行为;

　　6、注意防寒防暑，尽量避免感冒发烧或者腹泻;如有任何不适请先让翻译咨询主治医生，不能随意用药;

　　7、促排期间可能出现腹胀、胸胀、恶心、乏力、失眠、透明白带增多、体重增加、腰围增大、针口处瘙痒有红疹等不良反应，属于促排的正常现象，不必担心，但是如果出现如下体瘙痒、有异味等其他异常现象，请及时通知翻译联系主治医生;

　　8、每天大概同一时间段打针(前后误差2小时左右)，为了平均针眼，左右轮流打(肚皮注射)，一般都是有专业护士上门打针，会准时去打，确保打针时间不要外出就好;

　　9、用药谨遵医嘱，不能擅自停药或减药;

　　**婴方促排需要注意：**

　　1、与女方一样，婴方同样需要多摄入高蛋白食物：鱼类，牡蛎，海参，干果等以及蔬菜水果，精子质量不好的可按医嘱适量服用维生素片或锌片类;

　　2、婴方避免蒸桑拿、洗过热的热水，尽量宽松着装，少抽或不抽烟;

　　3、取卵前3-5天，婴方需要自行手淫更新精液，待取卵当日再取精。
